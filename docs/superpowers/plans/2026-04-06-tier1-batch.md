## Task 4: `mbqc` — isTest Flag with Filter

**Goal**: Boolean `isTest` payload field + enum filter (exclude/include/only).

**Detection**: regex map by language, matching on file name only (not
directory):

```typescript
const TEST_PATTERNS: Record<string, RegExp> = {
  typescript: /\.(test|spec)\.(ts|tsx|js|jsx)$/,
  javascript: /\.(test|spec)\.(ts|tsx|js|jsx)$/,
  python: /(^|[\\/])test_.*\.py$|_test\.py$/,
  java: /(Test|IT)\.java$/,
  go: /_test\.go$/,
  rust: /_test\.rs$/,
  ruby: /_(spec|test)\.rb$/,
  php: /Test\.php$/,
  c_sharp: /[Tt]ests?\.cs$/,
  cpp: /[Tt]ests?\.(cpp|cc|cxx)$/,
  c: /[Tt]ests?\.c$/,
  swift: /Tests?\.swift$/,
  kotlin: /Test\.kt$/,
  dart: /_test\.dart$/,
  scala: /(Spec|Test)\.scala$/,
  clojure: /_test\.clj[s]?$/,
};
```

**Files**:

- CREATE `src/core/domains/trajectory/static/test-detection.ts` —
  detectTestFile(relativePath, language)
- MODIFY `src/core/domains/trajectory/static/provider.ts` — call in
  StaticPayloadBuilder.buildPayload()
- MODIFY `src/core/domains/trajectory/static/payload-signals.ts` — add
  descriptor
- MODIFY `src/core/domains/trajectory/static/filters.ts` — add FilterDescriptor
  (enum: exclude/include/only)
- MODIFY `src/mcp/tools/schemas.ts` — add testFile field to typedFilterFields()
- MODIFY tests

**Filter behavior** (same as documentation):

- `include` (default): no filtering
- `exclude`: `must_not: [{ key: "isTest", match: { value: true } }]`
- `only`: `must: [{ key: "isTest", match: { value: true } }]`
