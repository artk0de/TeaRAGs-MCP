# Split Agent Integration Articles Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to
> implement this plan task-by-task.

**Goal:** Split 3 large agent-integration articles into L3 Docusaurus sub-pages
with `prompt-examples.md` as the last page in each category.

**Architecture:** Each monolithic `.md` file becomes a directory with
`_category_.json`, `index.md`, thematic sub-pages, and `prompt-examples.md`.
Content is extracted by line ranges, headings promoted (H2→H1, H3→H2), imports
added per-page. Cross-references updated across the entire docs tree.

**Tech Stack:** Docusaurus, MDX, autogenerated sidebar
