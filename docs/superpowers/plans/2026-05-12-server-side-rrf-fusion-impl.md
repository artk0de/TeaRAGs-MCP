# Server-side RRF fusion — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> `dinopowers:subagent-driven-development` (recommended) or
> `dinopowers:executing-plans` to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace client-side min-max + linear-blend fusion in
`QdrantManager.hybridSearch` with a single Qdrant Query API call using
`prefetch` + RRF fusion (optionally weighted via `semanticWeight`).

**Architecture:** One `this.client.query()` call per hybrid search, both
sub-queries supplied as `prefetch[]`. RRF runs server-side. Public signature
stays compatible (`semanticWeight` becomes optional). `minMaxNorm` helper and
the dual-`search` path are deleted.

**Tech Stack:** TypeScript, vitest, @qdrant/js-client-rest 1.17.0 (bumped from
1.16.2 in Task 1), Qdrant server 1.17.

**Spec:** `docs/superpowers/specs/2026-05-12-server-side-rrf-fusion-design.md`

**Beads epic:** `tea-rags-mcp-gk1d`

---

## Task ordering rationale

1. **Task 1 (SDK bump) is non-negotiably first.** Without
   `@qdrant/js-client-rest@1.17.0`, the `rrf.weights` field does not exist in
   the typed schema and Task 3 will not type-check.
2. **Task 2 (RED tests) lands BEFORE Task 3 (impl).** Project rule: tests-first
   for all code changes (`.claude/CLAUDE.md` → step 3 TDD). The tests describe
   the new wire format and lock it as a golden contract before implementation.
3. **Task 2 also updates `test-helpers.ts` mock signature** in the same commit.
   The mock signature change is additive (optional 6th param) and not a
   compile-blocker on its own, but landing the test infrastructure in one commit
   keeps Task 3 focused on production code.
4. **Task 4 (comment cleanup) is last** — cosmetic, no behavior change.
5. **Task 5 is verification gate** — no code change, exists so the plan
   explicitly ends on a green checkpoint.

```typescript
  /**
   * Performs hybrid search combining dense and sparse retrieval using Qdrant's
   * server-side RRF (Reciprocal Rank Fusion) via the Query API. Issues a single
   * request with two prefetches.
   *
   * @param semanticWeight Optional weight for the dense sub-query in weighted RRF.
   *                       If omitted, plain RRF (equal weights, Qdrant default k)
   *                       is used. If provided, must be in [0, 1]; the sparse
   *                       weight is implicitly (1 - semanticWeight).
   */
  async hybridSearch(
    collectionName: string,
    denseVector: number[],
    sparseVector: SparseVector,
    fetchLimit: number,
    filter?: Record<string, unknown>,
    semanticWeight?: number,
  ): Promise<SearchResult[]> {
    if (semanticWeight !== undefined) {
      if (!Number.isFinite(semanticWeight) || semanticWeight < 0 || semanticWeight > 1) {
        throw new InvalidQueryError("semanticWeight must be a finite number in [0, 1]");
      }
    }

    let qdrantFilter: Record<string, unknown> | undefined;
    if (filter && Object.keys(filter).length > 0) {
      if (filter.must || filter.should || filter.must_not) {
        qdrantFilter = filter;
      } else {
        qdrantFilter = {
          must: Object.entries(filter).map(([key, value]) => ({
            key,
            match: { value },
          })),
        };
      }
    }

    const fusionQuery =
      semanticWeight === undefined
        ? { fusion: "rrf" as const }
        : { rrf: { weights: [semanticWeight, 1 - semanticWeight] } };

    try {
      const response = await this.call(async () =>
        this.client.query(collectionName, {
          prefetch: [
            { query: denseVector, using: "dense", limit: fetchLimit, filter: qdrantFilter },
            { query: sparseVector, using: "text", limit: fetchLimit, filter: qdrantFilter },
          ],
          query: fusionQuery,
          limit: fetchLimit,
          filter: qdrantFilter,
          with_payload: true,
        } as Parameters<QdrantClient["query"]>[1]),
      );

      return (response.points ?? []).map((point) => ({
        id: point.id,
        score: point.score ?? 0,
        payload: (point.payload as Record<string, unknown> | null | undefined) ?? undefined,
      }));
    } catch (error: unknown) {
      if (error instanceof QdrantUnavailableError) throw error;
      const errorData = error as { data?: { status?: { error?: string } }; message?: string };
      const errorMessage = errorData?.data?.status?.error || errorData?.message || String(error);
      throw new QdrantOperationError(
        "hybridSearch",
        `collection "${collectionName}": ${errorMessage}`,
        error instanceof Error ? error : undefined,
      );
    }
  }
```

/** Min-max normalize an array of scores to [0, 1]. */
function minMaxNorm(scores: number[]): number[] {
  if (scores.length === 0) return [];
  const min = Math.min(...scores);
  const max = Math.max(...scores);
  const range = max - min;
  if (range === 0) return scores.map(() => 1);
  return scores.map((s) => (s - min) / range);
}
