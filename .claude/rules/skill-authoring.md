# Skill Authoring — write once, run in three harnesses (navigator)

Navigator. Points at owning rules; copies none. Tags: [live] seen in a real run,
[static] read from docs/source/generator, [assumed] unverified.

## 1. Pipeline in one screen

| Step | Do                                                                                                                      |
| ---- | ----------------------------------------------------------------------------------------------------------------------- |
| 1    | Edit sources only: `plugins/<name>/**`, `scripts/gen-harness-*.ts`, `scripts/harness/*.ts`                              |
| 2    | `npm run gen:plugins` → `.claude-plugin/<name>/`, `harness/codex/`, `harness/cursor/`, marketplaces, `agent-context.ts` |
| 3    | Bump `plugins/<name>/.claude-plugin/plugin.json` (new file = minor, text = patch)                                       |
| 4    | Commit sources + generated together                                                                                     |
| 5    | Never hand-edit generated paths                                                                                         |

Not generated (hand-kept): `.claude-plugin/marketplace.json`,
`.claude-plugin/.benchmarks/*/evals.json` (eval cases).

| Rule                                      | Owns                                                                                                                        |
| ----------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| `.claude/rules/plugin-sources.md`         | Source vs generated paths, merge driver, generator-test properties                                                          |
| `.claude/rules/plugin-guidance-layers.md` | Which layer owns a fact: prime (state), tool schema (contract), resources+guides (reference/policy), core (always-on ≤3700) |
| `.claude/rules/plugin-versioning.md`      | Bump `plugin.json` per affected plugin on every `plugins/**` edit                                                           |
| `.claude/rules/caveman-compression.md`    | Skill description `full`, body `ultra`; output-format contracts never compressed                                            |

New knowledge → pick layer by `plugin-guidance-layers.md` first, then write the
skill text.

## 3. Cross-harness best practices

Evidence = Codex eval round of plan Task 22 (`T22 r<round>`).

Root problem: Codex runs the SAME text to different outcomes across sessions
(gate-preexisting-split: PASS r22, FAIL r23, text unchanged). Text present ≠
text followed. Every rule below removes a fork; emphasis (MUST, bold) removes
none.

| #   | Practice                                                                                                                                                                                                   | Evidence                                                              |
| --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| 1   | Output contract sits next to the step that writes it. Give literal lines to copy with slots, not descriptions ("describing compliance is not compliance")                                                  | (T22 r5, r11, r19: literal lines / skeletons)                         |
| 2   | Exception rule sits beside the routing row it modifies, says replace vs extend. No competing routing layers                                                                                                | (T22 r20: E9 routing table vs BREADTH)                                |
| 3   | Plan-only answer still owes every output contract; `[planned; not run]` only for tool results not gathered                                                                                                 | (T22 r11, r18)                                                        |
| 4   | Mandatory reference read named at the decision point; distant "MANDATORY" link is skipped                                                                                                                  | (T22 r5: mandatory opens)                                             |
| 5   | One file per read command                                                                                                                                                                                  | (T22 r17-r19; `one-file-read.sh`)                                     |
| 6   | Neutral examples only; never paste an eval case's input/answer into a skill                                                                                                                                | (eval-5 contamination)                                                |
| 7   | Raise a size cap when needed; never trim behaviour-carrying text to fit                                                                                                                                    | (r20 regressions)                                                     |
| 8   | Eval graders grade by expectation text only; no "strictness reference" from past rounds                                                                                                                    | (T22 r19: 6/16 → 11/16 on regrade)                                    |
| 9   | One canonical definition per output rule. Copies across SKILL.md / reference / wrapper, each with its own sub-branches, print on some runs only                                                            | (T22 r23: gate-preexisting-split; Step 7 answer block)                |
| 10  | Codex copies the skeleton line, treats prose elsewhere as optional: a must-appear item is a literal skeleton line                                                                                          | (T22 r23: risk 3 pagination stops)                                    |
| 11  | Every check gets its own literal output line; a silent check next to printed ones is dropped                                                                                                               | (T22 r23: verify-symbol-risk find_similar)                            |
| 12  | A literal line names when it prints ("the review held NOW, first"); a described state ("partial=true until…") is never printed                                                                             | (T22 r23: gate-partial-not-pass)                                      |
| 13  | Branch choice by words visible in the prompt (path / container word / component name), never by category labels the model guesses (domain vs concept)                                                      | (T22 r23: risk 2)                                                     |
| 14  | Example values in a branch become the default answer when the prompt shares a word: placeholders (`**/<dir>/**`), never real names                                                                         | (T22 r23: risk 2 `**/enrichment/**`)                                  |
| 15  | A missing observation never picks a branch ("tool not seen → off"); require positive evidence + a plan line naming its source                                                                              | (T22 r23: explore 25)                                                 |
| 16  | Specialised vs general call: say "adds" or "replaces" beside the rule; "beats X" reads as "skip X"                                                                                                         | (T22 r23: index-lag E5)                                               |
| 17  | A prelude names the call after it and forbids stopping ("index, then the answering call"); consent = literal step (`step 2 AskUserQuestion`), not "ask separately"                                         | (T22 r23: E7, E15)                                                    |
| 18  | Fallback branch = complete procedure (call, filter, literal answer line), placed BEFORE the main branch; a one-line stub gets the main branch's framing                                                    | (T22 r23: codegraph-presence 12)                                      |
| 19  | Conditional reference load ("open when step N runs") is a fork plan-only answers always take: decision tables live in SKILL.md or open in the answering turn                                               | (T22 r23: DDG eval-9/10)                                              |
| 20  | Routing carve-outs live where routing is decided: the frontmatter description and the competitor's NOT-clause, not the target's body. Scope line uses the body's own definition                            | (T22 r23: naming-modify-scope, v2 E7)                                 |
| 21  | A broad rule ("new file → DDG") captures specialised work unless the exception is a row in the SAME decision table                                                                                         | (T22 r23: writing-skills eval-6)                                      |
| 22  | Internal recipe: handoff signature (input names) in the description's first sentence + "you are the callee" atop the body; else a prompt naming the caller runs the caller's flow                          | (T22 r23: working-tree S7)                                            |
| 23  | Exclusion in the routing row itself: a "tools = mcp**tea-rags**\*" header + generic "text search" row sent FIXME to a tea-rags tool                                                                        | (T22 r23: search-cascade 8)                                           |
| 24  | A case passing only next to certain neighbours leans on their context: the prompt alone lacks the trigger → fix the case (or core routing), not the skill description                                      | (T22 r23: verification eval-11)                                       |
| 25  | Availability of another plugin's skill = read its installed file, never its presence in the skills list (list truncated to a char budget; combined tea-rags + dinopowers ≈12.4k > Codex ~8k default)       | (T22 r24: 8 answers stopped to "install superpowers" that was cached) |
| 26  | A wrapper never restates its callee's call shape or output line; it points at the callee's step. Caller + callee each printing their own copy of one line fork                                             | (T22 r25: tdd-red-before-code, bug-hunt parallel block)               |
| 27  | A "describe the call" rule carries the literal call (`semantic_search(path=…, pathPattern=…, rerank=…)`); prose about parameters is paraphrased away                                                       | (T22 r25: writing-plans Step 2)                                       |
| 28  | A disqualifying-word branch ("process noun last → concept") goes BEFORE the pass test it overrides; placed after, the pass test has already answered                                                       | (T22 r25: risk 2 LOCATION TEST)                                       |
| 29  | An example next to a template IS the template: its field set and order are copied, missing fields included                                                                                                 | (T22 r25: DDG naming-type-misfit `names[]`)                           |
| 30  | A skill description's trigger list is a routing layer: "fix bug Z" in a test wrapper sends production fixes there; scope NOT-clauses route them back                                                       | (T22 r25: dinopowers TDD vs DDG)                                      |
| 31  | Wrapping skill prose with textwrap: `break_on_hyphens=False`, or `tea-rags` splits at the hyphen                                                                                                           | (T22 r25: lane B)                                                     |
| 32  | Name a routed skill by its installed file, resolved at hook run time: from `$name` alone Codex guesses a path (parent plugin, no `dino-` prefix), the read fails and the session answers without the skill | (T22 r26: DDG p6 0/5, every SKILL.md read missed)                     |
| 33  | A rule lives where the model actually reads in that flow: index-lag cases read core only, so a guide-only line never fires. Check the session log for which files were opened                              | (T22 r28-r30: E11 drift consent)                                      |
| 34  | No cross-references inside a step ("→ step 1"): restate the action ("own-checkout incremental"); Codex skips the unresolved reference                                                                      | (T22 r30-r31: E14)                                                    |
| 35  | Exception before the stop branch: "identifier lookup → find_symbol now" placed after "STOP, ask, WAIT" never fires                                                                                         | (T22 r28-r29: E12)                                                    |

## 4. Per-harness pitfalls

| Harness     | Pitfall                                                                                                                                                                           |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Claude Code | Source IS the Claude dialect; Codex/Cursor syntax in source breaks it. Load-time `!` works here only                                                                              |
| Claude Code | SKILL.md > 21500 bytes (15000 for architecture-diagnostics) fails `skill-size-budgets.test.sh`                                                                                    |
| Codex       | Skills list overflow (7000 / 5500) drops or shortens descriptions: new skill needs a short description                                                                            |
| Codex       | Truncated skills list hides installed dependencies (superpowers): an absent `$name` is not an absent plugin — check the cached `SKILL.md` path                                    |
| Codex       | No `!` inlining: next to every `` !`…` `` line keep a plain "read file/resource X" instruction                                                                                    |
| Codex       | Core past ~16 body lines loses rules: top rules first, core ≤ 3700 chars                                                                                                          |
| Codex       | Multi-file `cat`/loops hide the middle: one file per command                                                                                                                      |
| Codex       | Plugin hooks inert until trusted in `/hooks`                                                                                                                                      |
| Cursor      | No subagent/preCompact injection: rules a subagent needs must live in the skill text                                                                                              |
| Cursor      | Resource tool name/availability only observed: keep terminal fallback                                                                                                             |
| Cursor      | Everything [static]; no live run since cursor-agent needs a logged-in account (`harness/cursor/LIVE-TEST.md`)                                                                     |
| All         | Skill names: Cursor requires `name` = folder; wrappers rename to `dino-<s>` in Codex/Cursor, so refer to skills via transformable forms (`dinopowers:<s>`, `Skill(tea-rags:<s>)`) |

## 5. Pre-commit checklist

```bash
npm run gen:plugins
bash tests/hooks/skill-size-budgets.test.sh
bash tests/hooks/skill-resource-refs.test.sh
bash tests/hooks/codex-one-file-read.test.sh
npx vitest run tests/scripts/gen-harness-codex.test.ts
```

- Plugin version bumped (`plugin-versioning.md`), then `gen:plugins` re-run.
- Edited md formatted (prettier).
- Affected Codex eval cases re-run (cases in
  `.claude-plugin/.benchmarks/*/evals.json`).
- Generated diff reviewed: Codex skills-list totals in `harness/codex/README.md`
  still under 7000 / 5500.
