# H3: a class anchor is not a reason for a directory tour

H2 Q01 improves fresh control: 11→9 responses,429838→335653 input tokens,
142.8→106.4s, with required background callback retained and no truncation. H2
Q03 finally covers recording-hook scrubbing as well as all other original
points, but takes13 responses and505592 input tokens. H2 remains a fallback, not
a claim of superiority on every metric or against a new paired B run.

Its Q03 public waves show class-outline reads, later method-body requests, and
successive parent/sibling directory listings. For a class/container hit without
the needed member ids, file addressing already delivers a small file's full code
in one call, or a large file's member map. It avoids the class-header then
method-body cycle without broadening reads to a directory. Known method ids
still go straight to their bodies; freshness and held-body reuse do not change.

One rule correction, separate immutable native profiles: Q01/Q03 plus F01 entity
matching and W01 explicitly requested retry internals. Same model/effort/n1 and
frozen corpus/backend; no B/Claude run. Require all material quality points and
compare the whole Q01/Q03 pair, not best cases pooled across variants. Retain H2
if H3 fails quality or provides no defensible efficiency improvement.
