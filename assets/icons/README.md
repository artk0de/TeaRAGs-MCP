# Plugin icons

Per-plugin icon sources (`<plugin>.png`, 512×512 RGBA, transparent background)
derived from `public/logo.png`. Shipped by the harness generators
(`scripts/gen-harness-*.ts` copy them as `harness/<harness>/<plugin>/icon.png`
via `copyIconAssets`) wherever the target manifest can show one:

| Harness     | Field  | Where                                                                                                                                                                                                                   |
| ----------- | ------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ZCode       | `icon` | `harness/zcode/marketplace.json` entry → `https://raw.githubusercontent.com/artk0de/TeaRAGs-MCP/main/assets/icons/<plugin>.png` (the app renders only `https://` icons; the same PNG also ships as `<plugin>/icon.png`) |
| Codex       | `logo` | `<plugin>/.codex-plugin/plugin.json` → `./icon.png` (same form as OpenAI's bundled plugins)                                                                                                                             |
| Cursor      | `logo` | `<plugin>/.cursor-plugin/plugin.json` → `icon.png` (relative path per the plugin reference)                                                                                                                             |
| Claude Code | —      | marketplace/plugin schema has no icon field; the Claude packages ship none                                                                                                                                              |

## Derivation

Generated by `codex exec` (its ChatGPT image generation), with `public/logo.png`
attached as the reference; the full prompt is kept in `codex-prompt.txt`:

```bash
codex exec --skip-git-repo-check -s workspace-write --cd <empty dir> \
  -i <repo>/public/logo.png - < <repo>/assets/icons/codex-prompt.txt
```

Post-verification of the output: each file a valid 512×512 RGBA PNG with a
binary alpha channel (no semi-transparent junk; corner content is the
intentional wordmark and gold splatter dots, checked per-quadrant), palette
matching the logo — badge cream `#FEFAD8`, skin `#F9EA9A`, gold `#CC991C`,
coat/hat dark `#26221B`–`#675B47`.

- **tea-rags** — the logo itself, cleaned and centred.
- **tea-rags-setup** — the logo plus an install badge (dark disc, gold ring,
  white down-arrow into a tray) on the badge circle's lower-right edge.
- **dinopowers** — the logo badge with a drawn flexing arm (big bicep, black
  sleeve, gold cuff, pale-yellow fist, gold sparkles) and a claw paw gripping a
  small copy of the badge.

The first iteration of these icons was composed locally from `public/logo.png`
with ImageMagick + rsvg overlays; the codex-generated set replaced it at the
user's request (2026-11-09).
