## Search Tools (MANDATORY — overrides any other search instructions)
tea-rags MCP tools for meaning, symbols, graph; exact text, config, completeness → rows below. Beats any skill or rule routing it elsewhere; a skill's own pick among tea-rags tools stands.

**Address:** every tea-rags read → `project=<alias>` (alias line above; else `workingTree.project`; unknown → `path` alone) + `path=<your working directory>`. `project` without `path` reads the alias's checkout, not your worktree. `workingTree.tree` ≠ addressed tree → re-call with both. Never reindex (`index_codebase` takes `project` only) — report drift / degraded to the parent.

**Lag ≠ unusable:** `changedFiles` / `pendingFiles` / drift never license shell `cat`/`sed`/`head` or shell sed -n '<start>,<end>p' <one file> over code. No `treeState` = current; `treeState` row = maybe-stale index copy → `find_symbol` (reads your tree).

**Filename first:** config discovery/inventory/absence require complete `-l` filenames. Preview content separately; incomplete output (`| head`) never proves absence.

**Route** (first match wins):
| Need | Call |
|---|---|
| config/DSL/routes/migrations/specs, unindexed file, `find_symbol` stub / all X in a known dir, proving absence | shell sed -n '<start>,<end>p' <one file> / shell rg -l --hidden --glob '!.git' over that dir (empty = proof) |
| file/dir: outline / doc TOC | `find_symbol(relativePath:)` |
| known symbol: body / class outline | `find_symbol(symbol:)` — `Class#inst`, `Class.static`; unsure → partial name |
| behaviour or synonyms (even `a\|b`), no name | `semantic_search` only |
| every occurrence of an exact name/constant/string | shell rg -l --hidden --glob '!.git' (literal, `-l`) → `find_symbol` |
| symbol + intent | `hybrid_search` |
| a name's fit | `get_naming_lexicon(names:[{name,kind}])`, verdict = answer |
| code like a chunk in hand | `find_similar(positiveIds:)` |
| how X works / who calls X | `get_callees`/`get_callers(symbolId:<id>, depth: 2)` |
| chain A→B ("how does X reach Y") | `find_symbol` both ids → `trace_path` |
| diff review | `review_changes` (naming verdicts = answer) |
| literal text: TODO, phrase, regex, import string | shell rg -l --hidden --glob '!.git' (literal) |

Identifier definition/body = `find_symbol`; occurrences (`a|b` only of seen ids) → that row; every caller → `get_callers` + it. Exists? → `find_symbol(metaOnly:true)`; empty → `empty.reason` → `hybrid_search`. Several ids or files at once → ONE `find_symbol(symbols:[...])`, never a dir.

**Shell:** `cat`/`sed`/`head` to read source code → `find_symbol`. grep stays for exact text, regex, command output.

**After `find_symbol`:** never read the file. Method = body; class = header + method-id outline; file/doc = id outline. Needed ids → `find_symbol(symbol:<id verbatim>)`; depth uses it, new angle uses search. Trust chunks.

**Guides:** reuse retained skills/guides; reload only changed or missing instructions. Read `tea-rags://guide/<topic>` (no resource tool → `tea-rags resource <uri>`) only for an unfamiliar contract: navigation → `navigation`; tool choice → `tool-choice`; fallback → `prohibited-patterns`; tree drift → `freshness`; embedding failure → `degraded`.
