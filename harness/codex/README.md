## Layout

- `<repo>/.agents/plugins/marketplace.json` — marketplace `tea-rags`; the
  repository root is its root, `source.path` = `./harness/codex/<plugin>`.
- `tea-rags/.codex-plugin/plugin.json` — manifest: `skills`, `mcpServers`,
  `hooks` paths.
- `tea-rags/.mcp.json` — stdio server `tea-rags server`, tool calls
  pre-approved.
- `tea-rags/hooks/hooks.json` — SessionStart, two hooks in order:
  `${PLUGIN_ROOT}/scripts/session-start.sh` (core rules, `scripts/core.txt`),
  then `${PLUGIN_ROOT}/scripts/session-digest.sh` (`tea-rags prime "$PWD"`
  fitted by `scripts/fit-digest.py`), each its own
  `hookSpecificOutput.additionalContext` (core ≤ 9650, digest ≤ 9500 chars);
  SubagentStart `${PLUGIN_ROOT}/scripts/subagent-block.sh`
  (`hookSpecificOutput.additionalContext`). PreToolUse
  (`^(Bash|shell|exec_command)$`) `${PLUGIN_ROOT}/scripts/one-file-read.sh` —
  exit 2 for a shell command that prints two or more `.md` files (one file per
  command keeps a skill's output contract in view).
- `tea-rags/skills/` — curated tea-rags skills (below).
- `tea-rags/repair/`, `tea-rags/rules/references/` — plugin files the skills
  link to by relative path.
- `tea-rags/skills/tea-rags-core/` — `rules/core.md` as an always-relevant
  skill; every session gets it from the SessionStart hook; `AGENTS.tea-rags.md`
  — the same text, optional for your `AGENTS.md` (plugins cannot ship
  AGENTS.md).
- `dinopowers/.codex-plugin/plugin.json` — manifest: `skills`, `hooks` (no MCP
  server: the wrappers call the tea-rags plugin's tools).
- `dinopowers/hooks/hooks.json` — SessionStart `scripts/main-session-routing.sh`
  and SubagentStart `scripts/wrapper-routing.sh`, both
  `hookSpecificOutput.additionalContext` with the routing table
  (`scripts/*.txt`, rendered from the Claude Code hook scripts in `$dino-<s>`
  mentions).
- `dinopowers/skills/dino-<s>/` — the wrappers; `dinopowers/CHAINING.md`,
  `dinopowers/FRESHNESS.md` — files they link to.

## Install

```bash
codex plugin marketplace add <owner/repo> --sparse .agents --sparse harness/codex
# or a local clone: codex plugin marketplace add <path to the clone root>
codex plugin add tea-rags@tea-rags
codex plugin add dinopowers@tea-rags   # needs superpowers: https://github.com/obra/superpowers
```

Then review the plugin hooks in `/hooks` (plugin hooks stay untrusted until
reviewed; `codex exec` takes `--dangerously-bypass-hook-trust` for one run).
Development build instead of the global binary: in the installed `.mcp.json` set
`"command": "node", "args": ["<repo>/build/index.js"]`.

## Transform rules

Load-time `` !`…` `` blocks dropped (the model-read line beside them stays);
`ReadMcpResourceTool` → `read_mcp_resource`; `mcp__tea-rags__<tool>` → `<tool>`;
`Skill(tea-rags:<s>)` / `/tea-rags:<s>` / `tea-rags:<s>` → `$<s>`;
`dinopowers:<s>` → `<s>` in tea-rags, `$dino-<s>` in dinopowers
(`superpowers:<s>` → `$<s>` there); Agent-tool passages → "spawn a subagent";
`AskUserQuestion` → ask the user; `CLAUDE_PLUGIN_ROOT` → `PLUGIN_ROOT`,
`CLAUDE_PROJECT_DIR` → `PWD`; frontmatter → `name` + `description`.

## Facts (codex-cli 0.162.1; full list with sources: `docs/superpowers/specs/2026-10-23-harness-facts.md` §A)

- Manifest `.codex-plugin/plugin.json`; paths start with `./`
  [S:codex-rs/core-plugins/src/manifest.rs].
- Plugin hooks default to `hooks/hooks.json`; commands get `PLUGIN_ROOT`,
  `PLUGIN_DATA`; untrusted until reviewed in `/hooks`
  [D:learn.chatgpt.com/docs/hooks].
- Plain stdout is context for SessionStart / UserPromptSubmit / SubagentStart;
  structured `hookSpecificOutput.additionalContext`; ~2,500 tokens per hook
  output [D:hooks].
- Skills list = 2% of context (8,000 chars default); descriptions shortened
  first, skills omitted with a warning [D:learn.chatgpt.com/docs/build-skills].
  Measured (2026-10-26, 55 skills): each description clipped to ~467–470 chars,
  mid-word, no warning [L:codex skills-list probe].
- No manifest field bundles AGENTS.md — core rules go into a skill and a user
  AGENTS.md snippet.
- Resource tools: `list_mcp_resources`, `read_mcp_resource{server, uri}`
  [S:mcp_resource_spec.rs]; model-visible MCP tool names may carry an
  `mcp__<server>__` prefix — prose names tools bare.
- Verified locally (2026-10-23): `codex plugin --help` →
  `add | list | marketplace | remove`; `codex plugin marketplace --help` →
  `add | list | upgrade | remove`; `marketplace add <SOURCE>` takes a local
  path; `plugin add <PLUGIN[@MARKETPLACE]>`. A local marketplace root holds
  `.agents/plugins/marketplace.json` with `source.path` relative to the root
  [L:~/.codex/.tmp/bundled-marketplaces/openai-bundled].
- `.mcp.json` `type`: stdio entries in shipped plugins carry no `type` (3 of 3);
  only the HTTP entry has `"type": "http"`
  [L:~/.codex/plugins/cache/**/.mcp.json] — the stdio entry here omits it.
