# tea-rags for Cursor

GENERATED by `scripts/gen-harness-cursor.ts` from `plugins/tea-rags/` — do not
edit. Plugin version 0.47.31. Live-tested only up to the Cursor login: see
`LIVE-TEST.md`; run the open `MANUAL-TEST.md` checks before relying on it.

Rendered from `plugins/tea-rags/skills/**`, `plugins/tea-rags/rules/core.md` and
the plugin version. Try an edit locally with `npm run gen:plugins`; the release
regenerates this package and commits it.

## Layout

- `tea-rags/.cursor-plugin/plugin.json` — manifest; components come from the
  default folders.
- `tea-rags/mcp.json` — stdio server `tea-rags server` (explicit `type`,
  required for plugins).
- `tea-rags/hooks/hooks.json` — `sessionStart` →
  `bash "${CURSOR_PLUGIN_ROOT}/scripts/session-start.sh"`, which prints
  `{ "additional_context": "<tea-rags prime output>" }` (capped at Cursor's
  10000 chars) for `CURSOR_PROJECT_DIR` (else stdin `workspace_roots[0]`; plugin
  hooks run in the plugin directory, so never `$PWD`). `tea-rags` comes from
  `TEA_RAGS_BIN`, `PATH` or the usual global bin folders. No `subagentStart` /
  `preCompact` hooks: Cursor cannot inject context there.
- `tea-rags/skills/` — the tea-rags skills (17): every user-invocable one plus
  each internal skill a shipped skill names.
- `dinopowers/` — the wrappers as `skills/dino-<s>/` (Claude Code
  `dinopowers:<s>`; `superpowers:<s>` → `/<s>`), `CHAINING.md` / `FRESHNESS.md`
  they link to, and a `sessionStart` hook (`scripts/session-start.sh`) answering
  with the main-session routing table (`scripts/main-session-routing.txt`). No
  MCP server: the wrappers call tea-rags'. superpowers is not bundled — install
  it per https://github.com/obra/superpowers; a wrapper without it stops and
  asks.
- `tea-rags/repair/`, `tea-rags/references/` — plugin files the skills link to.
  `rules/references/` moves to `references/` (links rewritten) so `rules/` holds
  rule files only.
- `tea-rags/rules/tea-rags-core.mdc` — `rules/core.md` as an `alwaysApply: true`
  rule, with the terminal fallback for resource reads.

## Install (UNVERIFIED — second-hand, facts §B.1)

Marketplace: the repository root carries `.cursor-plugin/marketplace.json`
(`source` = `./harness/cursor/<plugin>`); add the repository as a marketplace
where your Cursor build supports it (UNVERIFIED, see `MANUAL-TEST.md`). Local
copy:

```bash
mkdir -p ~/.cursor/plugins/local
cp -R <repo>/harness/cursor/tea-rags ~/.cursor/plugins/local/tea-rags   # copy, do not symlink out of the folder
```

Then Reload Window. Enterprise workspaces need "Allow Local Plugin Imports".
Development build instead of the global binary: in the installed `mcp.json` set
`"command": "node", "args": ["<repo>/build/index.js"]`. The hook and the
terminal resource fallback still call `tea-rags` — point `TEA_RAGS_BIN` / `PATH`
at a build that has the `resource` command.

Seen in cursor-agent 2026.10.22-27dcf5f (`LIVE-TEST.md`): it reads
`~/.cursor/plugins/local/`, takes `--plugin-dir <path>` per plugin, and adds
marketplaces only from a git URL indexed for a logged-in account
(`agent plugin marketplace add <gitUrl> [--git-ref]`) — a local checkout cannot
be added as a marketplace.

## Transform rules

Codex rules (`scripts/harness/transform.ts`) with Cursor's dialect: skills
mentioned as `/<skill>`; `ReadMcpResourceTool` / `ListMcpResourcesTool` →
`FetchMcpResource` / `ListMcpResources` (observed names); `CLAUDE_PLUGIN_ROOT` →
`CURSOR_PLUGIN_ROOT`, `CLAUDE_PROJECT_DIR` → `PWD`; frontmatter → `name` (=
folder) + `description`. Every file naming a `tea-rags://` URI gets the terminal
fallback `tea-rags resource "<uri>" --path "$PWD"` under its title.

## Facts (docs only; full list with sources: `docs/superpowers/specs/2026-10-23-harness-facts.md` §B)

- Manifest `.cursor-plugin/plugin.json`: required `name`; optional description,
  version, author, homepage, repository, license, keywords, logo, rules, agents,
  skills, commands, hooks, mcpServers, variables. Default folders
  `skills/<n>/SKILL.md`, `rules/*.{md,mdc,markdown}`, `hooks/hooks.json`, root
  `mcp.json`; a manifest path replaces discovery for that component
  [D:cursor.com/docs/reference/plugins].
- Rules `.mdc`: `description`, `globs`, `alwaysApply` (true = every session);
  keep under 500 lines [D:cursor.com/docs/context/rules].
- hooks.json `{"version":1,"hooks":{"<event>":[{command, timeout, …}]}}`;
  sessionStart may return `env` and `additional_context`, fire-and-forget;
  subagentStart returns only `permission` / `user_message`; preCompact is
  observational [D:cursor.com/docs/hooks].
- Plugin MCP servers must declare `type`; `${CURSOR_PLUGIN_ROOT}` expands in
  command, args, env, cwd [D:reference/plugins].
- Skills: `name` lowercase-hyphen, equal to the folder; `description` required;
  invoked by description or `/skill-name` [D:cursor.com/docs/context/skills].
- Model-side MCP resource tools are not documented; forum reports
  `ListMcpResources` / `FetchMcpResource` and staff said resources were partly
  disabled — OBSERVED ONLY, hence the terminal fallback [F:forum.cursor.com].
- `cursor-agent -p --output-format json|stream-json`, `--force`,
  `--approve-mcps`, `--workspace`; whether plugin hooks fire in `-p` mode is
  UNVERIFIED [D:cursor.com/docs/cli/reference/parameters].
