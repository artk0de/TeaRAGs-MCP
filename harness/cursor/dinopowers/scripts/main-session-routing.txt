## dinopowers wrapper routing (applies to this session)

Matching intent → dinopowers wrapper, not the direct superpowers:* skill — even if
a global rule names superpowers:*. Wrapper runs tea-rags enrichment, then chains
into superpowers itself; nothing skipped.

| User asks to... | Invoke |
|---|---|
| Write / change production code outside a written plan (it owns RED + GREEN) | /data-driven-generation |
| Brainstorm / design a feature or refactor in a code area | /dino-brainstorming |
| Risky areas / what to know before refactoring X (research, no design) | /risk-assessment / /explore |
| Write an implementation plan | /dino-writing-plans |
| Execute a written plan that edits files | /dino-executing-plans |
| Debug a bug, error, stack trace, test failure | /dino-systematic-debugging |
| Write a failing test only, no production change; find / extract test patterns or conventions | /dino-test-driven-development |
| Verify before commit / PR / claiming done | /dino-verification-before-completion |
| Request a code review / open a PR | /dino-requesting-code-review |
| React to a review comment naming a symbol or file | /dino-receiving-code-review |
| Finalize a dev branch (merge / PR / cleanup) | /dino-finishing-a-development-branch |
| Author a SKILL.md in plugins/dinopowers/ | /dino-writing-skills |

row (typo or one-word fix — in a SKILL.md too: direct Edit, no writing-skills;
