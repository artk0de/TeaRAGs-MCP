## Fixes

- The hook took the project from `$PWD`; Cursor runs plugin hooks in the plugin
  directory and passes the workspace as `CURSOR_PROJECT_DIR` (set from
  `workspacePath` in the CLI bundle). The script now reads `CURSOR_PROJECT_DIR`,
  then stdin `workspace_roots[0]`, else answers `{}`.
- Hook commands run as `bash "${CURSOR_PLUGIN_ROOT}/scripts/session-start.sh"`;
  `tea-rags` is resolved through `TEA_RAGS_BIN`, `PATH`, then the usual global
  bin folders.
- cursor-agent rejects `additional_context` over 10000 chars
  (`HookAdditionalContextTooLargeError`); both hooks now cap it.
