When contacts merge, TaxDome reconciles both the **local send records** and the provider’s **taxpayer entities**.

- If the surviving contact already has a tax-preparation envelope for the same account and year, TaxDome moves the source envelope’s send records to it, except where the survivor already has a record for the same document, provider, and return type.
- Otherwise, TaxDome updates the source envelope to point to the surviving contact.
- It then asks the selected provider adapter to merge the contacts’ provider records. For Instead, entities move to the surviving contact; if both contacts have an entity of the same type, their provider documents are reassigned to the survivor’s entity and the source entity is unlinked.
- Any source envelope left over is destroyed through the provider cleanup path before the envelope is deleted.

So files already sent are not blindly resent. Their send records and vendor-side document links are carried through the merge when possible; duplicate records already represented under the survivor are handled by the cleanup path.
