For a repeated send of the **same document to the same provider, account/contact, tax year, and return type**, the shared entry point rejects it before calling the vendor. It returns the document in `rejected_documents` with reason `already_sent`.

There are two document-level pre-send refusals:

- **`already_sent`** — upload completed, and the provider has not archived the document. This applies even if processing later failed: the provider still holds the file.
- **`upload_in_progress`** — its upload is still `waiting` or `uploading`, so another send could race it.

An archived send is eligible to be sent again. These checks are scoped to the same provider and tax-preparation envelope; a different return type or envelope is evaluated separately.
