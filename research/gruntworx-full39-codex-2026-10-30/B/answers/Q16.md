### Registry constants

In `TaxPreparation::TaxAutomations::Registry`:

- `UnknownProviderError`
- `ADAPTERS` — provider key → adapter namespace; currently `{ instead: TaxPreparation::TaxAutomations::Instead }`
- `FEATURE_FLAGS` — provider key → availability feature flag; currently `{ instead: :tax_automations_instead }`

### Public methods

The module exposes these methods via `module_function`:

- `adapter_for_provider(provider)` — resolve a provider key or raise `UnknownProviderError`
- `client_for(connection)` — build the client for a connection’s adapter
- `adapter_for(firm)` — resolve the firm’s selected provider’s adapter
- `provider_of(adapter)` — get the provider key registered for a namespace
- `adapters` — return all registered adapter namespaces
- `provider_for(firm)` — read the firm’s selected provider, or `nil`
- `connection_for(firm)` — return its selected provider’s connection, in any state
- `connections_for(firm_id)` — return connections for all adapters, keyed by provider
- `usable_connection_for(firm)` — return a usable connection, or `nil`
- `capabilities_for(firm)` — get the selected adapter’s capability passport
- `provider_available?(provider, firm)` — check feature availability
- `sending_available?(firm)` — check availability for the firm’s selected provider
