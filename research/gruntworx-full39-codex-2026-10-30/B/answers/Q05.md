**`.xlsm` appears storable as a client document, but it is not configured as previewable.**

The document settings use a blacklist rather than an extension allowlist. That blacklist doesn’t include `xlsm`, so the extension alone doesn’t block storage. Uploads still have other checks, including MIME type and file size.

The previewable extension pattern explicitly lists `xls` and `xlsx`, but not `xlsm`. So TaxDome’s configured preview flow should not generate an inline preview for an `.xlsm` file; users can still access the stored file through the normal document flow.
