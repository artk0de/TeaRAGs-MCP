### Registry API

Constants in `TaxPreparation::TaxAutomations::Registry`:

- `ADAPTERS` — provider key → adapter namespace. Currently only `instead` is registered.
- `FEATURE_FLAGS` — provider key → firm feature flag. Currently `instead` maps to `tax_automations_instead`.
- `UnknownProviderError` — raised when no adapter is registered for a provider.

Public methods:

- `adapters`
- `adapter_for_provider(provider)`
- `client_for(firm)`
- `adapter_for(firm)`
- `provider_of(adapter)`
- `provider_for(firm)`
- `connection_for(firm)`
- `connections_for(firm)`
- `usable_connection_for(firm)`
- `capabilities_for(firm)`
- `provider_available?(provider, firm)`
- `sending_available?(firm)`

### Places that iterate over all registered adapters in `app/`

1. [DestroyCleanup](/Users/Shared/nav-ab/repo-master/app/services/tax_preparation/tax_automations/firms/destroy_cleanup.rb:51) calls each adapter’s `DestroyForFirm` when cleaning up a deleted firm.
2. [ReconcileSweepWorker](/Users/Shared/nav-ab/repo-master/app/workers/tax_preparation/tax_automations/documents/reconcile_sweep_worker.rb:21) runs the reconciliation candidate sweep for each provider.
3. [KeepAliveWorker](/Users/Shared/nav-ab/repo-master/app/workers/tax_preparation/tax_automations/connections/keep_alive_worker.rb:14) finds each adapter’s connected grants nearing expiry and schedules renewals.

`Registry.adapters` itself returns `ADAPTERS.values`; it is the source of the full adapter list, not another iteration site.
