`.xlsm` should be **storable**, but TaxDome does **not** currently mark it as previewable.

The client-document model rejects extensions on a **blacklist**. `.xlsm` isn’t on it, so it isn’t blocked by that extension check. Previewability has a separate allowlist: [config/settings.yml](/Users/Shared/nav-ab/repo-master/config/settings.yml:1098) lists `xls` and `xlsx`, but not `xlsm`. Since the model’s `previewable?` check uses that list, an `.xlsm` file won’t qualify for TaxDome’s document preview.

The frontend has an Office viewer path for files categorized as Excel, but the extension alone doesn’t establish that an `.xlsm` will reach it. In short: **storage, likely yes; preview through the normal TaxDome flow, no.**
