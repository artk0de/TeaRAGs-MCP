A repeat **does not reach the vendor** if every selected document is rejected by pre-send validation. If some documents pass, the provider receives the accepted subset; the others are returned as per-document rejections.

The validator checks two relevant cases:

- **Already sent:** rejects with `already_sent` when the same document has an uploaded, non-archived record for the same provider, client, contact, tax year, and return type.
- **Still in flight:** rejects with `upload_in_progress` when an earlier record for that provider, client, contact, and tax year is `waiting` or `uploading`. This check does not filter by return type.

A failed attempt can be sent again. An archived upload can also be sent again because it no longer counts as a file the provider holds.
