The send record has two independent AASM state machines in [TaxAutomations::Document](/Users/Shared/nav-ab/repo-master/app/models/tax_preparation/tax_automations/document.rb:39).

**Processing status** — initial state: `sent`.

| Event | Allowed transition |
|---|---|
| `start_processing` | `sent`, `error` → `processing` |
| `complete_processing` | `sent`, `processing` → `processed` |
| `fail_processing(reason)` | `sent`, `processing` → `error`; stores the reason |
| `exceed_limit` | `sent`, `processing` → `exceeded`; stores `exceeded` as the reason |
| `archive` | `sent`, `processing`, `processed`, `error`, `exceeded` → `archived` |
| `resend` | `processing`, `processed`, `error`, `archived`, `exceeded` → `sent` |

**Upload status** — initial state: `waiting`.

| Event | Allowed transition |
|---|---|
| `upload` | `waiting`, `uploaded`, `failed` → `uploading` |
| `finish` | `uploading` → `uploaded`; sets `uploaded_at` |
| `fail(reason)` | `waiting`, `uploading` → `failed`; stores the reason |
| `reset` | `uploading`, `uploaded`, `failed` → `waiting` |

Transitions clear `failure_reason` when the new state is not `error`/`exceeded` for processing status or `failed` for upload status.
