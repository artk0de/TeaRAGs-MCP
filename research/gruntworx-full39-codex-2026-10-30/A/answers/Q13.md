The firm is pinned to the vendor account ID (`external_tenant_uuid`) returned during connection. On the first connect with a nonblank ID, TaxDome saves it. A later connect to the **same provider** must report that same ID; a mismatch returns `account_mismatch`. The failed transaction rolls back the new connection, and TaxDome then tries to revoke the stray grant. The existing connection and binding remain in place. Switching providers clears the old binding so the new provider can establish its own.

If the vendor returns **no account ID**, TaxDome skips the binding check and continues the connection flow. It leaves any existing binding unchanged; if none exists, the firm remains unbound.
