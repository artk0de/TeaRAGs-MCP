**TaxDome merges the local send history into the surviving contact. It does not move, delete or resend files at the vendor.**

For each source contact’s tax-preparation envelope:

| Situation | Local behavior |
|---|---|
| Target has no envelope for the same account and year | Change the envelope’s `contact_id` to the target |
| Target already has that envelope | Move nonduplicate send records into it, then delete the source envelope |
| Both envelopes contain the same document + provider + return type | Keep the target’s send record; delete the source duplicate during cleanup |

Moved send records retain their statuses and vendor references.

Instead also merges its **local entity mappings**: it reassigns the source entity to the surviving contact, or moves local vendor-document references under an existing target entity of the same type. It then deletes the redundant TaxDome-created entity row or unlinks a vendor-origin entity row. **No vendor API call performs a corresponding remote merge.**

One limitation: the entity-merge hook runs only for the firm’s **currently selected provider**.
