**Usually, the second send is rejected before reaching the vendor.** Shared validation checks prior send records for the same firm, account, contact, tax year, provider and return type.

| Existing send | Pre-send refusal |
|---|---|
| Upload is `uploaded`, processing is anything except `archived` | `already_sent` |
| Upload is `waiting` or `uploading` | `upload_in_progress` |
| Upload is `failed` | Neither duplicate refusal; eligible for retry |
| Upload is `uploaded`, processing is `archived` | Neither duplicate refusal; eligible for re-send |

These are **per-document rejections** in `rejected_documents`. Other accepted files can proceed. If every file is rejected, the adapter’s export is never called.

Notably, a document whose upload succeeded but processing failed still receives `already_sent`.
