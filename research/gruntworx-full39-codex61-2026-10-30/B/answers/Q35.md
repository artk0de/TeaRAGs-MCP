Tax automations can get name parts through the internal CRM Public API:

```ruby
result = Crm::Api::Contact.find(
  firm:, user:, actor:, contact_id:
)

result.data.first_name
result.data.last_name
```

Instead already uses this lookup. For batches, `Crm::Api::Contact.list_by_ids(firm:, user:, actor:, contact_ids:)` also returns `first_name` and `last_name`.

**Neither currently exposes the contact UUID (`contacts.uid`).** The database column exists, but it is absent from the Public API mapping and typed result contracts. GruntWorx therefore needs CRM’s API extended to expose it.

| Call | Name parts | Contact UUID |
|---|---|---|
| `Contact.find` | Yes | No |
| `Contact.list_by_ids` | Yes | No |
| `Contact.list_by_account` | Only combined `name` | No |
