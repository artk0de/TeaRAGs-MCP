**An `.xlsm` file can be stored as a client document, but it is not currently previewable in TaxDome.**

Storage and preview use separate rules:

| Format | Storage permitted | Preview enabled |
|---|---|---|
| PDF | Yes | Yes |
| XLS | Yes | Yes |
| XLSM | Yes | No |

Storage uses an extension **blocklist**, rather than an allowlist. None of these three extensions is blocked. Normal file-size, filename and access validations still apply. See [document validation](/Users/Shared/nav-ab/repo-master/app/models/tax_preparation/document.rb:1050).

Preview uses a separate **allowlist**, which includes `pdf`, `xls` and `xlsx`, but excludes `xlsm`. Both backend and frontend consult that setting. See [extension settings](/Users/Shared/nav-ab/repo-master/config/settings.yml:1093) and [`previewable?`](/Users/Shared/nav-ab/repo-master/app/models/tax_preparation/document.rb:843).

For the GruntWorx spec: preserve XLSM results as downloadable originals. If inline preview is required, it needs additional implementation and viewer compatibility verification; adding the extension alone would not establish support.
