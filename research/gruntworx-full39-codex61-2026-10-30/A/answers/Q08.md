**Binary MiB**, despite the field being named `max_file_size_mb`.

[`ValidateDocuments#unsupported_file`](/Users/Shared/nav-ab/repo-master/app/services/tax_preparation/tax_automations/export/validate_documents.rb:116) converts the value using Rails’ `.megabytes`, which means `1024²` bytes, and rejects files only when their size exceeds that limit.

For GWX, set:

```ruby
max_file_size_mb: 50
```

That permits **52,428,800 bytes (50 MiB)**, including a file exactly that size.
