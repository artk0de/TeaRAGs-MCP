**What it was.** [`Instead::Mock::Adapter`](/Users/Shared/nav-ab/repo-master/app/lib/tax_preparation/tax_automations/instead/mock/adapter.rb:15) is a custom `Faraday::Adapter`. It replaces the network transport underneath the real client, preserving JSON parsing, HTTP error mapping, OAuth handling and metrics. It delegates requests to an in-process [`Mock::Router`](/Users/Shared/nav-ab/repo-master/app/lib/tax_preparation/tax_automations/instead/mock/router.rb:3).

The router emulates:

- OAuth token exchange/refresh and revoke;
- entity listing and creation;
- starting uploads, finalizing documents and fetching documents;
- vendor-shaped errors for unknown endpoints and missing entity headers.

It is **stateless**: UUIDv5 handles derive deterministically from the firm and request input. Entity creation does not change subsequent listings; document processing does not progress over time. Upload responses contain synthetic S3 POST credentials. It is a limited API simulation, not a complete vendor emulator.
