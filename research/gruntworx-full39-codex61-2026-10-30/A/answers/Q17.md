**Yes: [`firm_site_backups`](/Users/Shared/nav-ab/repo-master/config/storage.yml:30)** is the closest existing template. It uses `S3Cutover` with purpose-specific bucket and credential variables:

| Setting | Dedicated environment variable |
|---|---|
| Access key | `FIRM_SITE_BACKUPS_S3_ACCESS_KEY_ID` |
| Secret key | `FIRM_SITE_BACKUPS_S3_SECRET_ACCESS_KEY` |
| Bucket | `FIRM_SITE_BACKUPS_S3_BUCKET` |
| Region | Shared `AWS_REGION`, default `us-east-1` |

Each dedicated credential/bucket setting falls back to the main S3 setting, so **separation requires populating those dedicated variables**.

There is also [`amazon_tax_software_backups`](/Users/Shared/nav-ab/repo-master/config/storage.yml:26), but it separates only the bucket and inherits the shared credentials. For a vendor-facing bucket requiring separate credentials, `firm_site_backups` is the better configuration example.
