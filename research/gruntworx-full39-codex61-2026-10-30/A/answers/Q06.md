Ниже — сквозная таблица **TD ↔ GWX**. Сторона TD подтверждена кодом. По GWX подтверждены только названные вами форматы результатов — **PDF, XLS, XLSM**; документация API в контексте недоступна, поэтому точные имена полей, операций и статусов GWX не подставляю предположениями.

`Уточнить` означает, что соответствие нужно установить по контракту GWX.

| Область | TaxDome — текущий контракт | GruntWorx / соответствие | Статус |
|---|---|---|---|
| Провайдер | `FirmSettings.provider = gruntworx`, enum `1` | GruntWorx | Значение TD уже есть |
| Регистрация | `Registry::ADAPTERS` | Namespace адаптера GWX | Пока не зарегистрирован |
| Фирма | `firm_id` | Аккаунт / организация GWX | Уточнить идентификатор и кардинальность |
| Привязка аккаунта | `FirmSettings.external_tenant_uuid` | Идентификатор аккаунта GWX | Уточнить тип; поле TD предполагает одну привязку на фирму |
| Автор подключения | `creator_type`, `creator_id`: Owner / Employee | Пользователь, предоставивший доступ | Уточнить, существует ли такой субъект в GWX |
| Учётные данные | Access token + refresh token, сроки действия | Механизм аутентификации GWX | Уточнить; текущий контракт TD зависит от OAuth |
| Начало подключения | `Authorizations::Create → authorization_url` | Операция подключения GWX | Уточнить совместимость |
| Завершение подключения | `Connections::Create(code:, redirect_uri:)` | Подтверждение доступа GWX | Уточнить совместимость |
| Состояние подключения | `disconnected`, `connected`, `expired`, `revoked` | Состояния доступа GWX | Нужен отдельный маппинг |
| Отключение | Локальный disconnect + асинхронный revoke | Отзыв доступа GWX | Уточнить наличие операции |
| Клиент CRM | `client_id` | Клиент / налогоплательщик GWX | Уточнить сущность и внешний ID |
| Контакт CRM | `contact_id` | Физлицо / налогоплательщик GWX | Уточнить; не переносить модель Instead автоматически |
| Конверт декларации | `TaxAutomations::TaxPreparation` | Соответствующая единица обработки GWX | Уточнить: декларация, пакет, заказ или другая сущность |
| Налоговый год | `TaxPreparation.year` | Год обработки GWX | Уточнить поле и допустимые значения |
| Тип декларации | `return_type` | Тип декларации / продукта GWX | Нужна таблица кодов GWX |
| Типы деклараций TD | `1040`, `1120`, `1120S`, `1065`, `1041`, `706`, `709`, `990`, `5500`, `2290`, `1120F` | Поддерживаемые типы GWX | Соответствия пока не подтверждены |
| Данные бизнеса | `business_name`, `ein`; EIN в формате `XX-XXXXXXX` | Имя и налоговый идентификатор GWX | Уточнить поля и обязательность |
| Данные физлица | Имя и фамилия контакта CRM | Поля налогоплательщика GWX | Уточнить |
| Существующее соответствие клиента | Vendor-specific запись с внешним ID | Идентификатор клиента GWX | Нужна модель адаптера |
| Автоматическое сопоставление | Общего порта нет; matching Instead находится в его адаптере | Правила поиска / связывания GWX | Определить отдельно |
| Исходный файл | `TaxPreparation::Document` + blob | Входной файл GWX | Уточнить способ загрузки и метаданные |
| Запись отправки | `TaxAutomations::Document` | Внешняя отправка / элемент обработки GWX | Уточнить связь: один файл или пакет |
| Ключ отправки TD | `(firm, tax_preparation, document, provider, return_type)` | Ключ идемпотентности / внешний ID GWX | Уточнить; не считать эти ключи эквивалентными |
| Запуск обработки | `adapter::ExportAsync` | Операция отправки / запуска GWX | Нужен точный API-контракт |
| Передача байтов | Адаптер владеет workflow; общий helper поддерживает multipart signed POST | Upload-протокол GWX | Уточнить; PUT/direct upload потребуют другого пути |

| Уведомления | Webhook-обработка внутри адаптера | События / доставка GWX | Уточнить наличие, подпись и повторы |

| Получение результатов | В рассмотренных портах отдельного контракта импорта результатов нет | Результаты GWX | Нужно определить контракт получения и сохранения |
| Результат PDF | Обычный клиентский документ TD | PDF GWX → `.pdf` | Хранение разрешено, preview поддерживается |
| Результат XLS | Обычный клиентский документ TD | XLS GWX → `.xls` | Хранение разрешено, preview поддерживается |

| Исправления портов | Содержание TD-102837 недоступно | Требования совместимости с GWX | Обязательная зависимость спецификации |
