**An `.xlsm` file is allowed for storage, but is not currently marked previewable.**

TaxDome uses separate rules:

- **Storage:** document extensions use a blacklist, not an allowlist. Neither `.pdf`, `.xls` nor `.xlsm` is blocked. Normal size, MIME and antivirus checks still apply. See [document settings](/Users/Shared/nav-ab/repo-master/config/settings.yml:1093).
- **Preview:** the configured preview list explicitly includes `pdf`, `xls` and `xlsx`, but **not `xlsm`**. [`Document#previewable?`](/Users/Shared/nav-ab/repo-master/app/models/tax_preparation/document.rb:843) checks that list and requires a positive file size.

| GruntWorx result | Extension permits storage | Eligible for built-in preview |
|---|---|---|
| PDF | Yes | Yes |
| XLS | Yes | Yes |
| XLSM | Yes | No |

For the GruntWorx specs, preserve `.xlsm` as a downloadable original and treat preview support as a separate requirement. Adding it to the preview list alone would not establish that the preview renderer supports it.
