**Processing status** — initial state: `sent`

| Event | From | To | Side effect |
|---|---|---|---|
| `start_processing` | `sent`, `error` | `processing` | |
| `complete_processing` | `sent`, `processing` | `processed` | |
| `fail_processing(reason = nil)` | `sent`, `processing` | `error` | Assigns `failure_reason` |
| `exceed_limit` | `sent`, `processing` | `exceeded` | Sets reason to `exceeded` |
| `archive` | `sent`, `processing`, `processed`, `error`, `exceeded` | `archived` | |
| `resend` | `processing`, `processed`, `error`, `archived`, `exceeded` | `sent` | |

After every processing transition, `failure_reason` is cleared unless the destination is `error` or `exceeded`.

Direct `sent → processed` is permitted. `error → processed` requires passing through `processing`. `resend` is the only exit from `processed`, `archived` or `exceeded`.

**Upload status** — initial state: `waiting`

| Event | From | To | Side effect |
|---|---|---|---|
| `upload` | `waiting`, `uploaded`, `failed` | `uploading` | |
| `finish` | `uploading` | `uploaded` | Sets `uploaded_at = Time.current` |
| `fail(reason)` | `waiting`, `uploading` | `failed` | Assigns `failure_reason` |
| `reset` | `uploading`, `uploaded`, `failed` | `waiting` | |

After every upload transition, `failure_reason` is cleared unless the destination is `failed`.

These are **independent state machines**; transitioning one does not automatically transition the other. They share the same `failure_reason` field.
